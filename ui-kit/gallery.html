1. 令牌层（theme.css）

每套主题**恰好 21 个**令牌（tests/theme_check.py 既查缺少也查多余）。 下面的色块是从**当前生效的** :root 上现读的，切换主题会跟着变。
配对契约：--bg-* / --tint-* 配 --ink； --fill-* 配 --on-fill。深色模式下 --fill-* 会反转成浅底， 所以 --on-fill 是**近黑色** —— 混用就是浅字压浅底。

7. 浮层（overlays.css）

  

    所有浮层真实都是 position: fixed；演示台里被画廊样式改成 absolute 才钉得住。
    显隐必须靠 visibility + .is-open，
    不能靠 display —— 否则没法过渡。
    因此它们显式顶回全局的 [hidden]{display:none!important}：
    .modal[hidden]{display:grid}、.notice[hidden]{display:flex!important}。
  


  

    
模态 .modal（is-open + is-settled）

    

      旋入动画 = rotateX(--enter-rx) + translate + scale 三个属性同长同缓动。
      落定后（is-settled）会把 transform 移出过渡列表 ——
      否则跟随效果每帧改 --nx/--ny 都会重启过渡，在一个带 backdrop-filter
      的 fixed 盒子上每帧触发一次 Layout（实测 Layout +88 → +15）。
      毛玻璃在 3D 关闭时改成「落定后才开」。

8. 卡片编辑器（editor.css）

  

    #cardIcons.iconpick 带 ID 是**故意的**：预设模态的容器也带
    .iconpick，如果这里写裸 .iconpick，
    同特异性下后加载的 editor.css 会把 drawer.css
    给预设写的 display:grid 悄悄压掉。
  


  

    
编辑器双列 + 参数行

    

      .cardedit 自带 max-height 与内部滚动；
      .pspec 是「标签 / 控件 / 说明」三行网格，说明占满整行。
      响应式断点（900 / 1400）在 editor.css 末尾，**会改 filecard/drawer 的组件**。
    

    

      

        

          

            
            
          

          
参数 3 项

          
把输入转成 FLAC（无损）。压缩级别越高越慢、文件越小。

          

            

              
压缩级别compression_level

              

              
0–12，默认 5。范围用 0..12 表示。

            

            

              
保留标签keep_tags

              

              
关掉后会写出一份干净的标签集。

            

            

              
采样率sample_rate

              

              
这一项在当前组合下不生效（--off 置灰）。

            

            

              
备注note

              

              
这一项不需要说明。

    9. 状态钩子：哪些是 JS 写的
    
  
    
    改样式前先确认有没有 JS 在写这些钩子。完整清单见 README.md §6.1。
  
    
  
    
    
    钩子谁写作用
    
    
      
    --nx --nybindFollow()归一化指针位置（−1..1），继承给整个子树
    
      
    --mx --mybindFollow()指针像素位置，给网点与光晕做径向遮罩原点
    
      
    html[data-fx="off"]3D 开关关掉跟随：不叠毛玻璃、不给跟随动画
    
      
    html[data-theme-switch]switchTheme()主题切换期间静音全部 transition
    
      
    data-vt-dir / --vt-d / --vt-rswitchTheme()视图过渡方向与几何
    
      
    --drawer-top --drawer-box --drawer-left抽屉逻辑三档几何（左边取侧栏实际渲染宽度）
    
      
    is-open / is-settledopenModal / closeModal模态两阶段动效
    
      
    is-focused is-checked is-playing卡片交互文件卡片三态
    
      
    is-added链逻辑卡片/快照「已加入执行链」的对勾
    
      
    data-stop data-open data-dragging抽屉手势三档 + 拖拽中关过渡
    
      
    data-collapsed分类段折叠true/false，靠 grid-template-rows 过渡
    
      
    data-search data-filtered搜索open / 有过滤词时按钮挂小点
    
      
    data-running链运行中.chainbar[data-running="true"] .btn--run
    
      
    aria-pressed / aria-checked各开关分段开关、图标选择器、3D 开关的**选中态**
